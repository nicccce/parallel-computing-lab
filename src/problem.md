## 3. 核心算法与总体流程

加权Jaccard相似度计算与连通分支构建是处理大规模聚类任务的核心计算瓶颈，两节点间的相似度评估规模随数据量呈 $O(N^2)$ 增长 。

### 总体执行流程

1. 读取FASTA序列文件 。


2. 对所有序列两两计算Weighted Jaccard相似度 。


3. 达到设定阈值则进行并查集合并 。


4. 执行并查集的路径压缩或拍平操作 。


5. 输出每个序列对应的parent节点 。



### 数据处理与加权Jaccard计算步骤

* 
**k-mer转换**：实验默认设置k=3，对每条序列滑窗统计3-mer频次，一条长为n的序列可产生n-k+1个k-mer 。


* 
**统计频次**：分别统计两条序列的k-mer频次，并存入两个独立的map中 。


* 
**交集与并集累加**：遍历第一个map，累加min（即交集）和max（即并集） 。


* 
**并集补齐**：遍历第二个map，补齐仅在其中出现的项以完善max 。


* 
**得出相似度**：返回min与max的比值 。

## 4. 程序编译与执行

### 文件与编译

* 源代码包含提供总体流程的 `wj.cpp` 以及用于解析蛋白质序列的 `kseq.h` 。


* 基础编译命令参考：`g++ -O3 wj.cpp -lz -o jaccard_cluster` 。


* 允许自行更改编译方式和参数，但必须留存相应的脚本文件或Makefile 。



### 程序执行

* 
**单线程样例执行**：`./jaccard_cluster <fasta_file> <threshold>` 。


* 
**多线程提交执行**：`./jaccard_cluster <number of threads> <fasta_file> <threshold>` 。



### 结果验证与计时

* 统一使用 `time` 命令统计端到端的整个程序运行时间（例如：`time ./jaccard_cluster test.fasta 0.85 > result.txt`） 。


* 如使用MPI模型，初始化时间必须包含在计时区中 。


* 将输出重定向至文本后，使用md5sum进行比对，以验证分组结果的正确性 。


* 
**数据集说明**：`test.fasta` 为稀疏数据集（相似边更少、簇更分散），`test2.fasta` 为高相似蛋白质序列数据集（簇更密集） 。

## 5. 优化策略与调试工具

* 可选用多线程或多进程的并行方式优化计算热点 。


* 建议尝试使用向量化、访存优化、Cache友好性优化等细粒度技术 。


* 优化环节可涵盖数据读入、核心计算与结果输出 。


* 允许采用不同的计算方法或简化算法，前提是必须保持计算结果一致 。


* 推荐使用 gdb、vtune、perf 等工具进行调试和性能分析 。
